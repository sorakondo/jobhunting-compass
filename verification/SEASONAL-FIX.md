# 季節別の結果と見出しの修正

実施日: 2026-10-21。プラグインバージョン: 0.2.1。

## 表示する案内

点数の計算とExcelの案内文は維持し、最低点が同じ場合に表示する案内を1つに絞る。

| 最低点が同じ分野 | 10月〜3月末 | 4月〜9月末 |
| --- | --- | --- |
| 自己分析・企業分析 | 自己分析 | 自己分析 |
| 自己分析・選考対策 | 選考対策 | 自己分析 |
| 企業分析・選考対策 | 選考対策 | 選考対策 |
| 3分野すべて | 選考対策 | 自己分析 |

時期は日本時間（Asia/Tokyo）で判定し、訪問者の端末のタイムゾーンに依存しない。9問すべてで④を選んだ場合は、季節によらず満点文のみを表示する。画面の案内と読み上げ用の通知は、同じ判定日時を使う。

## テーマによる見出し装飾

診断内のh2・h3に限って、背景・罫線・パディング・装飾用疑似要素を解除する。文字色は従来の紺または濃いグレーを維持し、白いカード上で表示する。他のページ見出しには適用しない。

`node tools/build-preview.cjs --theme` で、提供画像の濃い見出し背景を再現する確認ページ `preview-theme.html` を生成できる。再現用CSSはプラグインCSSより後に読み込み、テーマの読み込み順でも修正が効くことを確認した。再現用CSSはSWELLのソースではなく、確認ページだけで読み込む。本番では読み込まない。

## 検証

- Nodeの11テストが成功。4^9 = 262,144通りの回答を冬・夏の両方で検証し、総点・分野別点・同点時の案内が期待通りであることを確認。
- 12か月すべてと、日本時間の3月31日23:59:59.999／4月1日0:00、9月30日23:59:59.999／10月1日0:00、年をまたぐ日付を確認。
- ブラウザで同点3パターン・3分野同点・満点を実際に回答し、案内が1種類だけ表示され、読み上げ通知と一致することを確認。
- 幅375・390・430・768・1024・1440pxで開始・質問・結果の18画面を測定。診断内の見出しは背景透明・罫線なし・装飾なし。診断外の見出しは濃い背景のままであることを確認。
- 横スクロール、44px未満の操作対象、ボタン内の文字切れ、ブラウザの警告・エラーはなし。
- JavaScriptの構文チェックと `git diff --check` が成功。
